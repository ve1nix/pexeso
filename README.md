# Pexeso — Руны памяти

Игра на память в стилистике Hearthstone. Нужно находить пары одинаковых рун (цифры 1–10) до окончания времени и получать звёзды, очки и опыт для повышения ранга.

## Возможности

- Игровое поле на 2–10 пар (4–20 карт) с адаптивной длительностью раунда.
- Карточки в стиле Hearthstone: декоративная рамка, руна в магическом медальоне, 3D-переворот, подсветка совпадений.
- Таймер в виде мана-кристалла, счётчик найденных пар, HUD текущего ранга.
- Оценка раунда: 1–3 звезды, очки и XP.
- Прогресс игрока: 7 рангов, рекорды по каждой сложности, сохранение в `localStorage`.
- Три страницы: старт, игра, рейтинг.

## Стек

- React 18, TypeScript (strict), Vite 6

## Быстрый старт

Требуется Node.js 20+ и Yarn 4 (через Corepack).

```bash
corepack enable
yarn install
yarn dev
```

Приложение откроется по адресу, который напечатает Vite (обычно `http://localhost:5173`).

## Как играть

1. На стартовом экране выберите количество пар (чётное число от 2 до 10; пресеты или ручной ввод).
2. Откройте две карты. Совпадающие руны остаются открытыми, несовпадающие — закрываются при следующем ходе.
3. Найдите все пары, пока не истекло время.

Длительность раунда зависит от сложности: `5 с + 5 с за пару`, то есть 15 с для 2 пар и 55 с для 10 пар. Если время вышло, раунд начинается заново.

## Система рейтинга

Расчёт результата раунда (`entities/game/model/selectors.ts`):

```
minFlips  = 2 × pairsCount
accuracy  = min(1, minFlips / flips)
timeRatio = timeLeftMs / roundDurationMs
base      = 100 × pairsCount
score     = round(base × (1 + 0.5 × accuracy + 0.5 × timeRatio))
```

Звёзды определяются от отношения `score / maxScore`:
- 3 звезды — не менее 0.8;
- 2 звезды — не менее 0.55;
- 1 звезда — в остальных случаях.

За победу начисляется XP, равный числу очков. Ранги:

| Ранг | Порог XP |
| --- | --- |
| Дерево | 0 |
| Бронза | 2 000 |
| Серебро | 6 000 |
| Золото | 15 000 |
| Платина | 30 000 |
| Алмаз | 55 000 |
| Легенда | 90 000 |

На странице `/rating` показаны текущий ранг, прогресс, статистика и рекорды по каждой сложности: лучший счёт, лучшие звёзды, наименьшее число ходов и больше всего оставшегося времени. Рейтинг хранится локально в `localStorage` под ключом `pexeso.rating.v1`; там же можно сбросить прогресс.

## Архитектура

Проект следует Feature-Sliced Design. Направление зависимостей строго вниз:

```
app → pages → widgets → features → entities → shared
```

| Слой | Что находится |
| --- | --- |
| `app` | Точка входа, роутер, глобальные стили |
| `pages` | `game`, `start`, `rating` — страницы маршрутов |
| `widgets` | `game-board`, `page-layout`, `rating-summary` |
| `features` | `start-game` (форма запуска), `record-rating` (запись результата) |
| `entities` | `card`, `game`, `rating` — модели, сторы, селекторы, UI сущностей |
| `shared` | Конфиги, типы, утилиты, базовые UI-компоненты |

Каждый слой-слайс имеет `index.ts` (публичный API); глубокие импорты вглубь чужого слайса запрещены правилом ESLint.

Состояние хранится в двух zustand-сторах:

- `entities/game/model/store.ts` — игровой цикл, чистый редьюсер и управление интервалом таймера;
- `entities/rating/model/store.ts` — XP, ранги и рекорды с `persist`.

Побочные эффекты вынесены из редьюсера: таймер — в стор игры, запись результата — в подписку `features/record-rating/model/roundRecording.ts`, хранение — в `shared/lib/storage.ts`.

## Маршруты

| Путь | Страница |
| --- | --- |
| `/` | Стартовый экран и выбор сложности |
| `/game` | Игровое поле (при отсутствии активной игры редирект на `/`) |
| `/rating` | Рейтинг и рекорды |

## Тесты

8 тестовых файлов, 35 тестов. Покрываются:

- чистый редьюсер игры: колода, совпадения, промахи, победа, таймер;
- длительность раунда и расчёт результата (очки, звёзды);
- стор игры: тики и остановка таймера;
- рейтинг: XP, рекорды, дедупликация раундов, ранги;
- подписка на запись результата;
- валидация числа пар.
